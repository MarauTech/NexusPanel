Instalacja

Wybierz środowisko uruchomieniowe

Wklej poniższe polecenie bezpośrednio w konsoli węzła Proxmox VE (PVE Node Shell):

bash -c "$(curl -fsSL https://raw.githubusercontent.com/MarauTech/NexusPanel/main/install.sh)"
• Pobiera szablon Debian 12 i tworzy dedykowany kontener LXC (512 MB RAM, 1 vCPU, 4 GB SSD).
• Konfiguruje usługę autostartu systemd i wyświetla gotowy adres URL panelu.

Wklej w terminalu systemu Debian / Ubuntu / Raspberry Pi OS jako root:

bash -c "$(curl -fsSL https://raw.githubusercontent.com/MarauTech/NexusPanel/main/install.sh)"
Utwórz plik docker-compose.yml i uruchom docker compose up -d: 
services:
  nexuspanel:
    image: ghcr.io/marautech/nexuspanel:latest
    container_name: nexuspanel
    restart: unless-stopped
    ports:
      - "3000:3000"
    volumes:
      - ./data:/app/server/data
      - ./uploads:/app/uploads
    environment:
      - PORT=3000
      - NODE_ENV=production
      - JWT_SECRET=change-this-secret-key-to-something-random

FAQ

Często zadawane pytania

Czy NexusPanel wymaga zewnętrznej chmury lub konta?

Nie. NexusPanel jest w 100% rozwiązaniem self-hosted. Wszystkie dane, logi, ustawienia i telemetria są zapisywane w lokalnej bazie SQLite na Twoim serwerze. Aplikacja nie wysyła żadnych danych telemetrycznych na zewnątrz.

Jak działa automatyczny skaner podsieci LAN?

Skaner automatycznie identyfikuje lokalną podsieć serwera (np. 192.168.10.x) i równolegle odpytuje wszystkie 254 adresy IP pod kątem popularnych portów homelabowych (Proxmox :8006, Home Assistant :8123, Plex :32400, NAS :8001/:5000, Immich :2283). Odnalezione serwery można dodać do panelu jednym kliknięciem.

Jak działają widżety na smartfonie z Androidem?

Widżety są natywnymi komponentami Android AppWidget (obsługują Androida 8.0+). Komunikują się bezpośrednio z Twoim serwerem NexusPanel w sieci LAN / VPN, wyświetlają rzeczywisty czas pracy serwera, obciążenie CPU/RAM oraz logotypy usług. Kliknięcie w kafelek natychmiast otwiera daną usługę w domyślnej przeglądarce telefonu.

Jak zaktualizować NexusPanel do nowszej wersji?

W przypadku instalacji na Proxmox / Linux wystarczy wejść do katalogu aplikacji, wykonać git pull && npm install && npm run build && systemctl restart nexuspanel. W przypadku Dockera wystarczy pobrać nowy obraz poleceniem docker compose pull && docker compose up -d.
